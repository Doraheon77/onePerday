# onePerday
2026 AI컴퓨터공학부 심화캡스톤 onePerday팀 프로젝트용 github

# 작업 방식
- Repository Fork -> 개인 Repository에서 작업
- git branch 전략 적극 활용
 - Main : 바로 배포 가능
 - Develop : 다음 버전을 위한 개발
 - Feature : 추가 기능 개발
 - Release : 다음 버전 출시 준비. 테스트 및 QA 진행
 - hotfix : 버그 수정
- Merge시 -> Push나 Merge 절대 금지!!!! / Pull Request 기능 이용
- Pull request시, 작업 유형에 따라 Label 선택하여 구분
 - Bug(오류/버그) : 기능이 예상대로 작동하지 않을 때
 - Documentation(문서 관련) : 리드미(README), 위키, 주석 등 문서 수정이 필요할 때
 - Duplicate(중복) : 이미 보고된 이슈와 내용이 겹칠 때
 - Enhancement(기능 개선) : 기존 기능을 더 좋게 만들거나 새로운 제안을 할 때
 - Good first issue(초보용 이슈) : 프로젝트에 처음 기여하는 사람이 시도하기 좋은 쉬운 작업
 - Help wanted(도움 요청) : 메인테이너가 해결하기 어려워 커뮤니티의 도움이 필요할 때
 - Invalid(유효하지 않음) : 실제 이슈가 아니거나, 정보가 부족하여 진행할 수 없을 때
 - Question(질문) : 버그는 아니지만 코드나 프로젝트에 대해 궁금한 점이 있을 때
 - Wontfix(해결 안 함) : 의도된 동작이거나, 여러 이유로 수정하지 않기로 결정했을 때
